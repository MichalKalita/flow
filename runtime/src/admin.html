Memory and storage

Production target: 1 shared CPU and 2 GiB RAM. RSS measures the entire process. SQLite reports its own allocations. Component estimates exclude allocator overhead, fragmentation, active requests, thread stacks and other shared runtime allocations; they do not add up to RSS.
